Quick answers

Most likely the feature is compiled out. VITE_RT_PSO_DEBLOAT defaults to 1 and removes the shader permutations for RTXDI, path tracing, ray-traced translucency, caustics and per-pixel ray-traced GI. The variables still set; nothing renders. See Compile-Time Switches. Check whether its plugin is enabled. Most bundled plugins default to off — see Bundled Plugins. Usually a toolchain mismatch or missing .NET Framework 4.5 reference assemblies. See Build Troubleshooting. Stale cache. See Cache Management.
