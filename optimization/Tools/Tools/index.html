Tools and Automation

Vite ships batch tooling for the whole engine lifecycle: ViteSetup.bat for setup and building, RunUAT.bat for installed builds, the LocalBuilds\ scripts for packaging and registration, and WipeShaderCache.bat for when caches go stale.

Building Unreal from source involves a long sequence of steps, each with its own failure modes. Vite wraps that sequence in tooling so the common paths do not require remembering the exact command lines.

In this section

Topic Covers
ViteSetup Assistant The guided setup and build assistant, and its menu mode
Installed Builds Producing and packaging a redistributable binary engine
Cache Management Wiping shader and DDC caches when things go wrong

The tools at a glance

Tool Location Purpose
ViteSetup.bat Engine root Guided nine-step setup, or a menu of individual operations
RunUAT.bat Engine root Installed engine build via BuildGraph
WipeShaderCache.bat Engine root Clears engine-level shader and DDC caches
LocalBuilds\CompressBuild*.bat LocalBuilds\ Packages a staged installed build into a 7z archive
LocalBuilds\RegistryAdd.bat LocalBuilds\ Registers the build as UEViteFork
LocalBuilds\RegistryRemove.bat LocalBuilds\ Unregisters it
LocalBuilds\MakeShortcut.bat LocalBuilds\ Creates UEViteFork.lnk
devops\ueVite-debloat-*.bat devops\ Engine debloat suite — see Debloat Guide

Which one you want

Run ViteSetup.bat. It walks the whole sequence from environment check to a launched editor. See ViteSetup Assistant. Run ViteSetup.bat and choose the binary build option at step 4, or drive RunUAT.bat and the LocalBuilds\ scripts directly. See Installed Builds. Run WipeShaderCache.bat. See Cache Management. Run the devops\ debloat suite. See Debloat Guide. ViteSetup.bat menu and choose option 3, or run GenerateProjectFiles.bat directly.
