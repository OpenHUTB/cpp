# 古惑狼：时空扭曲

这是基于虚幻引擎 4.26 制作的《古惑狼3：时空穿梭》中“古墓探险者”关卡的社区重制版。这是一个完整的游戏关卡，而不是一个灯光场景。

![](../../img/optimization/CrashBandicootRemake.png)
*古墓丽影关卡重制版正在引擎中运行。这是一个完整的可玩关卡，而不是一个光照场景，这使得它的帧成本曲线更接近于一个真实的项目。*


## 来源

[dyanikoglu/CrashBandicoot-Timetwister](https://github.com/dyanikoglu/CrashBandicoot-Timetwister)

## 入选理由

本部分的大部分项目都是技术演示：一个场景，旨在展示某一项渲染功能。而这个项目则是一个可玩关卡，包含移动、碰撞、障碍物、收集品和摄像机系统，因此它是一种不同的参考案例。


它有两个用途：

- **游戏玩法驱动的性能分析。** 一个真实的关卡拥有与光照场景不同的帧成本特性：角色帧数、动画、碰撞查询和游戏逻辑都会与渲染竞争。这才是大多数项目实际的性能特点。参见[性能分析](../Performance/Profiling.md)部分。
- **证明 4.x 版本足以胜任。** 风格化的平台游戏正是 UE5 的主要功能会增加成本但实际提升并不显著的类型，而 4.27 版本更低的基础成本才是更佳的选择。参见[为何选择 NvRTX 4.27](../EngineOverview/Why-NvRTX-427.md)。

## 版本说明

**注意：** 本项目的目标引擎版本为虚幻引擎 4.26，而非 4.27。在 Vite 中打开时会提示引擎版本转换。预计会解决一些资源和 API 的差异；4.26 和 4.27 之间的差异虽小但并非为零。

相比从 UE5 迁移，这要容易得多，后者需要使用资源降级工具——请参阅[从 UE5 迁移](../GettingStarted/Migrating-From-UE5.md)。
